# REGAL 

The REGAL project is a dynamic online platform designed to empower students in their journey towards skill development, specifically for college placements. The platform provides a comprehensive suite of resources to enhance key competencies required for successful interview preparation and competitive exams, including Reasoning, English, General knowledge, Aptitude, and Logical reasoning. Developed using modern technologies such as HTML5, CSS3, JavaScript, PHP, and MySQL, REGAL offers a sleek, user-friendly interface that ensures a responsive and engaging learning experience. With its scalable architecture, the platform is built for future upgrades and enhancements, providing long-term value for students.

## Project Objectives

The REGAL platform is created to:

- Offer a **home page** displaying various educational resources categorized into Reasoning, English, General knowledge, Aptitude, and Logical aspects.
- Provide a **Categories Section** where students can access practice material for each skill set with a simple "Practice Now" button.
- Include a **Practice Section** that centralizes practice questions from all categories in one place, making it easy for students to hone their skills.
- Feature **Progress Bars** to track students’ learning progress and motivate them to keep advancing.

The platform focuses on a seamless learning experience, allowing students to easily access, practice, and track their growth.

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP
- **Database**: MySQL

## Installation steps

1. **Clone the Repository**: First, clone the repository to your local machine using the following command:

    ```bash
    git clone <repo-url>  

2. **Place the Code Folder**: Move the cloned code folder into your XAMPP `htdocs` directory.

    Example:  
    `C:\xampp\htdocs\regal-php\`  

3. **Run XAMPP**: Open the XAMPP control panel and start the **Apache** and **MySQL** servers.

4. **Set Up the Database**: 

    - Open your browser and go to `http://localhost/phpmyadmin/`.  
    - Create a **new database**.  
    - Import the `intern.sql` file (located in the project folder) into the newly created database.  

5. **Access the Platform**: 

    Open your browser and go to the following URL:  
    http://localhost/regal-php/
